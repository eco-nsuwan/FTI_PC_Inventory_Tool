LAYER 1

Native C# Host & Power Management Engine

ไฟล์หลัก: src/host/Program.cs และ app.manifest

.NET Framework 4.8 / 4.7.2

1. UAC Elevation Guarantee (app.manifest)

โปรแกรมถูกบังคับด้วยสิทธิ์ <requestedExecutionLevel level="requireAdministrator" /> ป้องกันข้อผิดพลาดด้านสิทธิ์ (Access Denied) เมื่อต้องส่งแพ็กเก็ตดิบ (Raw UDP Socket) ไปยังพอร์ต 137 หรือเรียกคำสั่ง System Power

2. Win32 Power State Guard (kernel32.dll)

ใช้ P/Invoke เรียก Native Win32 API: SetThreadExecutionState(ES_CONTINUOUS | ES_SYSTEM_REQUIRED | ES_AWAYMODE_REQUIRED); ทำให้ CPU และ Network Interface Card (NIC) ทำงานต่อเนื่องเต็มประสิทธิภาพ แม้ผู้ใช้จะล็อกหน้าจอคอมพิวเตอร์ทิ้งไว้

3. Laptop Lid-Close Protection (powercfg)

เมื่อเปิดโปรแกรม Host จะส่งคำสั่งสอบถามการตั้งค่าพับจอผ่าน powercfg /qh ทั้งโหมด AC และ DC แล้วบันทึกค่าเดิมไว้ที่ %LOCALAPPDATA%\FTI_PC_Inventory_Tool\lid_state.json จากนั้นตั้งค่าเป็น 0 (Do Nothing) เพื่อให้สามารถพับจอเดินไปมาหรือทิ้งไว้ข้ามคืนได้

4. Clean Lifecycle & Process Supervisor

ติดตั้ง Handler ดักจับ SetConsoleCtrlHandler และ AppDomain.CurrentDomain.ProcessExit หากโปรแกรมถูกปิดกะทันหัน ระบบจะกู้คืนค่า Lid Action และหยุดกระบวนการลูก (Child Process) ทั้งหมด ป้องกันโปรเซสค้างใน Task Manager

Program.cs (Key Implementation) P/Invoke Native API 
// 1. Win32 Flags to keep system alive
[Flags]
public enum EXECUTION_STATE : uint {
    ES_AWAYMODE_REQUIRED = 0x00000040,
    ES_CONTINUOUS        = 0x80000000,
    ES_SYSTEM_REQUIRED  = 0x00000001
}

[DllImport("kernel32.dll", CharSet = CharSet.Auto, SetLastError = true)]
public static extern EXECUTION_STATE SetThreadExecutionState(EXECUTION_STATE esFlags);

// 2. Enforce awake mode during scan
SetThreadExecutionState(
    EXECUTION_STATE.ES_CONTINUOUS |
    EXECUTION_STATE.ES_SYSTEM_REQUIRED |
    EXECUTION_STATE.ES_AWAYMODE_REQUIRED
);

// 3. Restore on exit
SetThreadExecutionState(EXECUTION_STATE.ES_CONTINUOUS);
💡 จุดสำคัญ: ไฟล์ Host ทำหน้าที่เป็น Launcher แตกไฟล์ script ที่บรรจุอยู่ภายในออกมาทำงานใน Memory โดยไม่ต้องติดตั้ง .NET Runtime อื่นเพิ่ม

🔌 REST API Endpoints Specification

Method Endpoint หน้าที่และการทำงาน Response
GET /api/status เช็คสถานะการสแกน (Idle, Scanning, Done) และ % ความคืบหน้า JSON Object
GET /api/inventory ดึงข้อมูลเครื่องที่สแกนเสร็จแล้วทั้งหมดมาแสดงในตาราง JSON Array
POST /api/scan/start ส่ง Targets, Range IP, และ Credentials เพื่อสั่งรัน Core Scanner { status: "started" }
POST /api/scan/stop สั่ง Cancel การสแกนทันทีและสั่ง Kill Runspace { status: "stopped" }
GET /api/export ดาวน์โหลดผลลัพธ์เป็นไฟล์ Excel หรือ CSV สรุปข้อมูล File Download

LAYER 3

Scanner Core & 2-Pass Penetration Engine

ไฟล์หลัก: src/Get-PCInventory.Core.ps1

Multi-Protocol Penetration
01

9-Port Pre-flight TCP Probe

ก่อนเริ่มเชื่อมต่อ WMI/CIM ระบบจะทำการยิงตรวจสอบ 9 พอร์ตสำคัญพร้อมกัน เพื่อจำแนกประเภทอุปกรณ์และเลือกเส้นทางเจาะที่เร็วที่สุด:

135 (RPC) 445 (SMB) 5985 (WinRM) 5986 (HTTPS) 3389 (RDP) 139 (NetBIOS) 80/443 (Web) 5900 (VNC)
02

Ghost-DNS Hunter (UDP 137)

แก้ปัญหาใหญ่ขององค์กรที่เครื่องเปลี่ยน IP แล้ว DNS Server ยังจำ IP เก่า:

  • ยิง NetBIOS Name Query บน Port UDP 137
  • ค้นหาเครื่องเป้าหมายที่แท้จริงจาก MAC/Hostname
  • สั่งเรียก Remote ipconfig /registerdns อัตโนมัติเพื่อล้าง Cache ทั้งระบบ
03

5-Stage Rescue Protocol

กลไก Failover อัตโนมัติ หากช่องทางหลักไม่สำเร็จ จะสลับโหมดถอยร่นทันที:

  1. Stage 1: WinRM (WS-Man 5985)
  2. Stage 2: Direct IP DCOM (NTLM)
  3. Stage 3: PSRemoting Session
  4. Stage 4: Remote Registry (445)
  5. Stage 5: Active Directory FQDN

ไดอะแกรมการทำงานของ 2-Pass Penetration

Pass 1 (Lightweight Discovery): ใช้เวลาเฉลี่ยเพียง 150ms ต่อเครื่อง เพื่อกรองว่าโฮสต์ใดมีตัวตนอยู่จริง พอร์ตใดเปิดอยู่บ้าง และมีสิทธิ์อนุญาตเข้าถึงระดับใด

Pass 2 (Deep Telemetry Extraction): สำหรับเครื่องที่ Pass 1 ผ่าน จะดึงข้อมูลลึกระดับฮาร์ดแวร์ BIOS, Motherboard Serial, RAM Slots, GPU Bus, BitLocker Key Status, Antivirus Engine และ Software List ทั้งหมด

กลไกนี้ช่วยลดภาระ Network Traffic ในองค์กรลงได้มากกว่า 70% เมื่อเทียบกับการสแกนตรงๆ แบบดั้งเดิม

LAYER 4

Executive Web Dashboard & Interactive Grid

ไฟล์หลัก: src/web/index.html

Vanilla JS + Modern CSS

1. Excel-Grade Drag Column Resizer

ผู้ใช้สามารถคลิกลากขอบคอลัมน์เพื่อปรับความกว้างได้อย่างอิสระ หรือ Double Click ที่เส้นขอบเพื่อ Auto-fit ตามความยาวข้อความ ค่าความกว้างทั้งหมดจะถูกบันทึกลงใน localStorage ของเบราว์เซอร์อัตโนมัติ

2. Executive KPI Cards & Interactive Charts

แสดงผลสรุปภาพรวมสำหรับผู้บริหาร: จำนวนเครื่องทั้งหมด, สถานะ Online/Offline, เวอร์ชันระบบปฏิบัติการ (Windows 10/11), กราฟแยกตามประเภท CPU (Intel vs AMD) และกราฟแยกตามหน่วยงาน

3. Actionable Watchlist with Click-to-Filter

แท็บคัดกรองเครื่องที่มีความเสี่ยงหรือผิดปกติโดยเฉพาะ เช่น เครื่องที่สแกนไม่ผ่าน, แรมเหลือน้อยกว่าเกณฑ์, หรือไม่มี Antivirus เมื่อคลิกการ์ด Watchlist ตารางจะทำการกรองเฉพาะเครื่องกลุ่มนั้นทันที

4. A4 Print Stylesheet

รองรับการกด Ctrl + P หรือปุ่ม Print เพื่อพิมพ์รายงานลงกระดาษ A4 สไตล์รายงานผู้บริหาร โดยระบบจะซ่อนปุ่มกดและตัดขอบหน้าจอออกอัตโนมัติ
